## Why This Matters
LLMs can explain chemistry, but they struggle with sequential experimental strategy. This environment targets that gap by forcing tradeoffs across potency, safety, selectivity, and cost over long horizons.

## OpenEnv Compliance
- Uses OpenEnv `Environment`, `Action`, `Observation`, `State`
- Uses OpenEnv HTTP server wrapper for standard env endpoints
- Follows Gym-style API: `reset`, `step`, `state`
- Keeps strict client/server separation
- Has valid manifest: [openenv.yaml](/Users/akshatvaja/Documents/akshat/work/Hackathon/drug-discovery-sim-env/openenv.yaml)

## Environment Summary
- 8 tools/actions: target, compounds, affinity, ADMET, modify, synthesize, validate, literature
- 5-stage campaign with budget constraints and stage progression
- Pathway topology + off-target propagation in state transitions
- Local large-data pipeline for offline reproducibility (`local_only` default)

## Reward Design (Advanced)
- Multi-objective core reward: terminal + process + reasoning + strategy
- Potential-based shaping to reinforce incremental scientific progress
- Anti-gaming penalties: repetitive-loop penalty and unsafe shortcut penalty
- Novelty pressure bonus for non-redundant exploration
- OpenEnv rubric composition integrated for composable scoring gates

## Local-Only Submission Workflow

1. Setup environment
```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -U pip setuptools wheel
python3 -m pip install -e .[training,test]
```

2. Configure tokens and runtime (optional)
```bash
cp .env.example .env
```
Fill `.env` values (for faster HF model pulls):
- `HF_TOKEN=...`

3. Download large local datasets
```bash
python3 -m drug_discovery_env.scripts.download_local_data --compound-limit 5000 --pubmed-per-query 250
python3 -m drug_discovery_env.scripts.prepare_snapshots
```

4. Validate
```bash
pytest -q
python3 -m drug_discovery_env.scripts.run_local_rollout --data-mode local_only
python3 -m drug_discovery_env.scripts.run_evaluation --episodes 5 --data-mode local_only
```

5. Train and generate plots
```bash
python3 -m drug_discovery_env.scripts.run_grpo --train --episodes 2 --data-mode local_only --device mps --model sshleifer/tiny-gpt2 --max-train-steps 10
python3 -m drug_discovery_env.scripts.run_training_experiment --episodes 2 --data-mode local_only --device auto --model sshleifer/tiny-gpt2 --max-train-steps 10 --out-dir artifacts/training
```

6. Run server for Space / local serving
```bash
uvicorn drug_discovery_env.server.app:app --host 0.0.0.0 --port 8000 --reload
```

7. Run client-side rollout/eval/train through running server (strict separation)
```bash
python3 -m drug_discovery_env.scripts.run_local_rollout --server-url http://127.0.0.1:8000
python3 -m drug_discovery_env.scripts.run_evaluation --episodes 5 --server-url http://127.0.0.1:8000
python3 -m drug_discovery_env.scripts.run_grpo --train --episodes 2 --server-url http://127.0.0.1:8000 --data-mode local_only --device mps --model sshleifer/tiny-gpt2 --max-train-steps 10
python3 -m drug_discovery_env.scripts.run_training_experiment --episodes 2 --server-url http://127.0.0.1:8000 --data-mode local_only --device mps --model sshleifer/tiny-gpt2 --max-train-steps 10 --out-dir artifacts/training
```
